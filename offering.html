01 — Cue Index

The knowledge foundation

We process your documents — whatever form they come in

📐 CAD drawings 🏗️ BIM models 📄 Contracts 🗺️ P&ID diagrams 🖨️ Scanned drawings 📊 Schedules 📑 Reports 📧 Correspondence

Our pipelines are purpose-built for the AEC industry

  • Read a title block on a scanned drawing
  • Extract obligations from a contract clause
  • Pull spatial hierarchy from an IFC model
  • Find valve tags and instrument loops on a P&ID

Entities and relationships are resolved across all documents — the same person, element or location is recognised wherever it appears

The result is a three-layer index

🔍
Full-text search

Find any passage in any document, instantly

🧠
Vector search

Find content by meaning, not just keywords

🕸️
Knowledge graph

Navigate relationships between every entity across your project

Every fact traces back to its source document

No black box — you can always see where an answer came from

The index is accessible from anywhere via MCP (for AI tools and agents) and a CLI

02 — Cue Tuner

Shape the index to your business

Before you start a project, the Tuner lets you define exactly what you care about

  • Specific entities or relationships to extract
  • Internal classification codes and breakdown structures
  • Business rules unique to your organisation

Connect your existing data to the graph

🏢 ERP systems 🔧 Work orders 👥 Employee directories 📦 Asset registers

Define mappings once — your structured data becomes part of the knowledge graph

Then validate what you've built

Run automated QA against the knowledge representation — checking for missing data, inconsistencies and rule violations

Precise rule-based checks and fuzzy matching to catch near-misses your team would never find manually

Together, the Index and Tuner give you a knowledge representation that is:

  • Complete — all document types, all disciplines
  • Transparent — every fact traces to its source
  • Auditable — validated against your business rules
  • Extensible — enriched with your existing data
  • AI-ready — consumable by agents, tools and apps

03 — Cue Studio

Build project apps in hours, not months

Studio puts the index in the hands of developers and builders

A JavaScript SDK for full control — and a library of ready-made components for common project data views

Ready-made components

  • 📋 Document list — auto-fetches metadata when you give it a list of IDs
  • 👁️ Document viewer — detects file type and picks the right viewer automatically
  • 🏢 Entity viewer — shows details with a live network graph of connections
  • 📌 Related documents — surfaces everything linked to an entity
  • 🗺️ Map — with AEC-specific GIS features built in

The Cue app builder skill means any coding agent can build a Cue app from a plain-English prompt

No deep technical knowledge required — just describe what you want
