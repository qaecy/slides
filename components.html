<cue-logo>

Animated QAECY logo — adapts to light and dark mode

<cue-logo> — API

Attribute Type Default Description
size 'xs' | 's' | 'm' | 'l' 'm' Size preset
active boolean true Plays the draw animation once on load. Set to false to skip it
continuous boolean false Loops the draw animation indefinitely

<cue-logo> — size presets

size="s"
size="m" (default)
size="l"

<cue-logo> — animation

↺ refresh to replay

active="false" — outlines once
active (default) — draws once
continuous — loops

<cue-logo> — dark & light mode

Colours adapt when class="dark" is present on <body>

⬤ toggle dark / light

<cue-logo> — dark & light mode

<!-- Dark mode -->
<body class="dark">
  <cue-logo size="m"></cue-logo>
</body>

<!-- Light mode -->
<body>
  <cue-logo size="m"></cue-logo>
</body>

<!-- Toggle at runtime -->
<script>
  document.body.classList.toggle('dark');
</script>

<cue-logo> — usage

<!-- Outline draw and out -->
<cue-logo size="l" active="false"></cue-logo>

<!-- Animated once on load (default behaviour) -->
<cue-logo size="m"></cue-logo>

<!-- Continuously looping -->
<cue-logo size="m" continuous></cue-logo>

<!-- Inline (scale to text size with CSS) -->
<style>
  .logo-inline { display: inline-block; height: 1em; vertical-align: middle; }
</style>
<cue-logo class="logo-inline" size="s"></cue-logo>

Loading via CDN

<!-- Static tags are detected automatically -->
<cue-logo size="m"></cue-logo>

<!-- Add the single loader script anywhere in the page -->
<script
  src="https://cdn.jsdelivr.net/npm/@qaecy/cue-ui@0.0.25/index.js"
  type="module"
></script>

<!-- Optional: include bundled styles -->
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@qaecy/cue-ui@0.0.25/styles.css"
/>

Components used only in JS (created dynamically) must be listed in data-components on the script tag

<cue-by-cue-logo>

Your company logo with app credits to Cue

<cue-by-cue-logo> — API

Attribute Type Default Description
src string — URL of your logo image
alt string — Alt text for the logo image
active boolean true Plays the Cue draw animation once on load
continuous boolean false Loops the draw animation indefinitely
--by-cue-logo-width CSS var — Controls the total component width

<cue-by-cue-logo> — animation

↺ refresh to replay

active (default) — draws once
continuous — loops
active="false" — no animation

<cue-by-cue-logo> — width

Use --by-cue-logo-width to scale the component

--by-cue-logo-width: 120px
--by-cue-logo-width: 220px
--by-cue-logo-width: 320px

<cue-by-cue-logo> — usage

<!-- Default (animates once on load) -->
<cue-by-cue-logo
  src="https://example.com/your-logo.svg"
  alt="Your company"
></cue-by-cue-logo>

<!-- Continuously looping -->
<cue-by-cue-logo src="..." alt="..." continuous></cue-by-cue-logo>

<!-- No animation -->
<cue-by-cue-logo src="..." alt="..." active="false"></cue-by-cue-logo>

<!-- Custom width -->
<cue-by-cue-logo
  src="..."
  alt="..."
  style="--by-cue-logo-width: 280px"
></cue-by-cue-logo>
